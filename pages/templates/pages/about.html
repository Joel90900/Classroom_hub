About this project

{{ purpose }}

ClassroomHub es una aplicación web didáctica desarrollada para demostrar los fundamentos y capacidades avanzadas del ecosistema Django, incluyendo arquitectura Modelo-Plantilla-Vista (MTV), persistencia en bases de datos relacionales MySQL/MariaDB, y control de accesos por roles (RBAC).

El sistema incorpora un CRUD robusto con vistas basadas en clases (CBV), formularios con validación en servidor mediante ModelForm, gestión de sesiones para métricas de usuario y una suite integral de 55 pruebas automatizadas que aseguran la fiabilidad del software.

Django 6.1.3 MariaDB / MySQL Arquitectura MTV Class-Based Views Gestión de Sesiones Control RBAC
